# Yurari demo

[Yurari](https://github.com/minittupoyo/astro-theme-yurari) のデモサイトを公開するためのリポジトリです。

**https://minittupoyo.github.io/astro-theme-yurari-demo/**

テーマ本体の `main` ブランチをビルドして GitHub Pages に公開します(`.github/workflows/deploy.yml`)。このリポジトリにテーマのコードはありません。

- テーマを更新したら、Actions タブの "Deploy demo to GitHub Pages" から **Run workflow** で再公開できます。
- 毎週月曜にも、自動で再公開します。
